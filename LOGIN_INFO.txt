🚀 كيفية تشغيل النظام - HOW TO START THE SYSTEM
===============================================================================

1. تشغيل Backend:
   - افتح Terminal في مجلد backend
   - قم بتشغيل: python run.py
   - سيعمل على: http://localhost:8000

2. تشغيل Frontend:
   - افتح Terminal في مجلد frontend
   - قم بتشغيل: npm run dev
   - سيعمل على: http://localhost:3000

3. أو استخدم الملفات الجاهزة:
   - start_backend.bat - لتشغيل Backend
   - start_frontend.bat - لتشغيل Frontend
   - run_system.bat - لتشغيل الاثنين معاً
